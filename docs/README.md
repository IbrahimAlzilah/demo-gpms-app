# توثيق مشروع نظام إدارة مشاريع التخرج (GPMS)

مرحباً بك في التوثيق الشامل لنظام إدارة مشاريع التخرج (Graduate Project Management System - GPMS).

## نظرة عامة

هذا النظام هو منصة متكاملة لإدارة دورة حياة مشاريع التخرج للطلاب في الجامعة. يوفر النظام بيئة منظمة وآمنة لإدارة جميع مراحل المشاريع من بداية المقترحات حتى التقييم النهائي والمناقشة.

## البنية التقنية

- **الواجهة الخلفية**: Laravel 12 (PHP 8.2+)
- **الواجهة الأمامية**: React 19 + TypeScript + Vite
- **قاعدة البيانات**: SQLite (قابل للتغيير إلى MySQL/PostgreSQL)
- **المصادقة**: Laravel Sanctum
- **التصميم**: TailwindCSS + Radix UI

## البدء السريع

للبدء في استخدام النظام، اتبع الخطوات التالية:

## ملاحظات مهمة

- جميع الوثائق مكتوبة باللغة العربية
- التوثيق موجه للمبتدئين والمطورين ذوي الخبرة
- جميع الأمثلة والشرح مبسطة وواضحة

إذا كنت تريد المساهمة في تحسين التوثيق، يرجى:
