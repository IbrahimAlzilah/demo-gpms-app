# توثيق نظام إدارة تقييم مشاريع التخرج (GPMS)

مرحباً بك في توثيق المشروع. هذا الملف يساعدك على **البدء** و**التنقل** بين ملفات التوثيق.

---

## كيفية استخدام التوثيق

- **إذا كنت جديداً على المشروع**: ابدأ بـ [00-overview.md](./00-overview.md) ثم [01-system-architecture.md](./01-system-architecture.md).
- **إذا تريد تشغيل المشروع محلياً**: انتقل مباشرة إلى [05-running-the-project.md](./05-running-the-project.md).
- **إذا تريد فهم الأدوار والصلاحيات**: راجع [08-user-roles-permissions.md](./08-user-roles-permissions.md).
- **إذا تريد فهم الـ Backend أو الـ API**: راجع [03-backend.md](./03-backend.md) و [07-api-reference.md](./07-api-reference.md).
- **إذا تريد فهم الواجهة الأمامية**: راجع [04-frontend.md](./04-frontend.md).
- **إذا تريد فهم قاعدة البيانات**: راجع [02-database.md](./02-database.md).
- **إذا تريد خطة تحسين أو إعادة هيكلة**: راجع [06-improvements.md](./06-improvements.md).
- **إذا تريد رؤية هيكل الملفات والمجلدات**: راجع [repository-tree.md](./repository-tree.md).

## ملاحظات

- التوثيق مكتوب **بالعربية** ليكون مناسباً للمطورين المبتدئين.
- أسماء التقنيات والمكتبات بالإنجليزية (مثل Laravel, React, API).
- الـ Backend و الـ Frontend موثّقان **بشكل مستقل** لسهولة القراءة.
- إذا وجدت خطأ أو غموضاً، يمكن تحديث الملف المناسب أو إضافة ملاحظة.
