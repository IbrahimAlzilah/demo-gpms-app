# الأدوار والصلاحيات (User Roles & Permissions)

هذا المستند يوضح **كل دور** في النظام، **ماذا يستطيع فعله**، و**ماذا لا يستطيع فعله**.

---

## 1. نظرة عامة على الأدوار

يحتوي النظام على **5 أدوار** رئيسية:

| الدور                                    | الوصف الموجز                              | المسارات في الواجهة                                                |
| ---------------------------------------- | ----------------------------------------- | ------------------------------------------------------------------ |
| **طالب (student)**                       | طالب جامعي في مرحلة مشروع التخرج          | `/dashboard`, `/proposals`, `/projects`, `/groups`, إلخ            |
| **مشرف (supervisor)**                    | عضو هيئة تدريس يشرف على مشاريع            | `/dashboard`, `/proposals`, `/supervision-requests`, `/evaluation` |
| **لجنة المشاريع (projects_committee)**   | لجنة لإدارة دورة مشاريع التخرج            | `/dashboard`, `/proposals`, `/projects`, `/periods`, إلخ           |
| **لجنة المناقشة (discussion_committee)** | لجنة لتقييم المشاريع في المناقشة النهائية | `/dashboard`, `/projects`, `/evaluation`                           |
| **مدير (admin)**                         | إدارة النظام بالكامل                      | `/dashboard`, `/users`, `/settings`, `/reports`                    |

---

## 2. شرح تفصيلي لكل دور

### الدور 1: الطالب (Student)

**من هو؟** طالب جامعي في مرحلة مشروع التخرج يريد تقديم مقترح، التسجيل على مشروع، رفع مستندات، وعرض درجاته.

**ما يستطيع فعله:**

| الميزة                 | الوصف                                                                 |
| ---------------------- | --------------------------------------------------------------------- |
| **تقديم مقترحات**      | إنشاء وتعديل مقترحات مشاريع (في نافذة زمنية محددة)                    |
| **إنشاء مجموعات**      | إنشاء مجموعة طلابية، دعوة أعضاء، قبول/رفض دعوات، طلبات انضمام لمجموعة |
| **التسجيل على مشاريع** | التسجيل على مشاريع مُعلَن عنها كمجموعة (في نافذة التسجيل)             |
| **رفع المستندات**      | رفع فصول، تقرير نهائي، عرض تقديمي (في نوافذ محددة)                    |
| **تقديم طلبات**        | طلبات تغيير مشرف، مجموعة، أو مشروع                                    |
| **عرض الدرجات**        | عرض درجاته في المشاريع التي شارك فيها                                 |
| **متابعة المشروع**     | عرض ملاحظات المشرف، المعالم، الاجتماعات                               |
| **عرض الإشعارات**      | استلام إشعارات عند موافقة، رفض، موعد، إلخ                             |

**ما لا يستطيع فعله:**

- الوصول لمسارات المشرف أو اللجان
- الموافقة على مقترحات أو تسجيلات
- توزيع لجان المناقشة
- تعديل إعدادات النظام أو إدارة المستخدمين

---

### الدور 2: المشرف (Supervisor)

**من هو؟** عضو هيئة تدريس يشرف على مشاريع التخرج ويقيّم الطلاب.

**ما يستطيع فعله:**

| الميزة                         | الوصف                                              |
| ------------------------------ | -------------------------------------------------- |
| **تقديم مقترحات**              | إنشاء مقترحات مشاريع (في نافذة تقديم المقترحات)    |
| **الموافقة على طلبات الإشراف** | الموافقة أو رفض طلبات الطلاب للانضمام كمشرف لمشروع |
| **تقييم المشاريع**             | رفع درجات التقييم للطلاب في المشاريع المعينة عليه  |
| **إضافة ملاحظات**              | إضافة ملاحظات للمشاريع، والرد على ردود الطلاب      |
| **إدارة المعالم**              | إنشاء معالم للمشروع، تحديثها، إكمالها              |
| **إدارة الاجتماعات**           | جدولة اجتماعات المشروع وتسجيل حضور الطلاب          |
| **مراجعة المستندات**           | الموافقة أو رفض المستندات المرفوعة                 |
| **عرض المشاريع المعينة**       | عرض مشاريعه فقط، وتقدمها، ودرجاتها                 |

**ما لا يستطيع فعله:**

- إعلان مشاريع للتسجيل
- معالجة التسجيلات أو الطلبات (من اختصاص لجنة المشاريع)
- توزيع لجان المناقشة
- الموافقة على الدرجات النهائية (من اختصاص لجنة المشاريع)
- إدارة المستخدمين أو الإعدادات

---

### الدور 3: لجنة المشاريع (Projects Committee)

**من هو؟** لجنة مسؤولة عن إدارة دورة مشاريع التخرج كاملة.

**ما تستطيع فعله:**

| الميزة                    | الوصف                                                                         |
| ------------------------- | ----------------------------------------------------------------------------- |
| **مراجعة المقترحات**      | عرض المقترحات المقدمة، الموافقة، الرفض، أو طلب التعديل                        |
| **إعلان المشاريع**        | إعلان المشاريع المعتمدة للتسجيل                                               |
| **تعيين المشرفين**        | تعيين مشرف على مشروع، أو طلب تعيين من لجنة أخرى                               |
| **معالجة التسجيلات**      | الموافقة أو رفض تسجيلات الطلاب على المشاريع                                   |
| **معالجة الطلبات**        | الموافقة أو رفض طلبات الطلاب (تغيير مشرف، مجموعة، مشروع)                      |
| **إدارة النوافذ الزمنية** | إنشاء وتعديل الفترات الزمنية (تقديم مقترحات، تسجيل، رفع مستندات، إلخ)         |
| **توزيع لجان المناقشة**   | توزيع أعضاء لجنة المناقشة على المشاريع (2–3 أعضاء لكل مشروع)                  |
| **الموافقة على الدرجات**  | الموافقة على الدرجات النهائية ونشرها                                          |
| **التقارير**              | عرض تقارير المشاريع، المشرفين، الطلاب، الطلبات، المواعيد، التصدير (PDF/Excel) |

**ما لا تستطيع فعله:**

- تقديم تقييم نهائي في المناقشة (من اختصاص لجنة المناقشة)
- إدارة المستخدمين أو الإعدادات (من اختصاص المدير)
- الوصول لمسارات الطالب أو المشرف العادي

---

### الدور 4: لجنة المناقشة (Discussion Committee)

**من هو؟** لجنة مسؤولة عن تقييم المشاريع في المناقشة النهائية (2–3 أعضاء لكل مشروع).

**ما تستطيع فعله:**

| الميزة                   | الوصف                                                      |
| ------------------------ | ---------------------------------------------------------- |
| **عرض المشاريع المعينة** | عرض المشاريع المعينة لها فقط                               |
| **تحميل المستندات**      | تحميل مستندات المشروع للمراجعة                             |
| **التقييم النهائي**      | رفع درجات المناقشة النهائية (في نافذة final_defense_phase) |

**ما لا تستطيع فعله:**

- مراجعة المقترحات أو الموافقة عليها
- إعلان المشاريع أو معالجة التسجيلات
- توزيع اللجان
- الموافقة على الدرجات أو نشرها (من اختصاص لجنة المشاريع)
- إدارة المستخدمين أو الإعدادات
- الوصول لمسارات لجنة المشاريع أو المدير

---

### الدور 5: المدير (Admin)

**من هو؟** شخص مسؤول عن إدارة النظام بالكامل.

**ما يستطيع فعله:**

| الميزة               | الوصف                                                                                             |
| -------------------- | ------------------------------------------------------------------------------------------------- |
| **إدارة المستخدمين** | إنشاء، تعديل، حذف المستخدمين بجميع الأدوار                                                        |
| **الإعدادات**        | تعديل إعدادات النظام (عدد أعضاء المجموعة، الحدود، إلخ)                                            |
| **التقارير الشاملة** | عرض تقارير المستخدمين، النظام، المشاريع، المشرفين، الطلاب، الطلبات، المواعيد، التصدير (PDF/Excel) |

**ما لا يستطيع فعله (ضمن منطق النظام الحالي):**

- لا يوجد قيود صلاحية للمدير داخل التطبيق؛ يستطيع الوصول لكل ما هو مخصص لدوره.

## 4. النوافذ الزمنية (Time Windows) وتأثيرها على الصلاحيات

بعض الإجراءات تعمل **فقط** ضمن نوافذ زمنية نشطة:

| النافذة                                                                                         | الوصف                      | من يستفيد منها |
| ----------------------------------------------------------------------------------------------- | -------------------------- | -------------- |
| `proposal_submission`                                                                           | تقديم المقترحات            | طالب، مشرف     |
| `project_registration`                                                                          | التسجيل على المشاريع       | طالب           |
| `chapter_submission_phase_1`, `chapter_submission_phase_2`, `final_project_document_submission` | رفع المستندات              | طالب           |
| `final_defense_phase_1`, `final_defense_phase_2`                                                | التقييم النهائي (المناقشة) | لجنة المناقشة  |
| `grade_approval`                                                                                | الموافقة على الدرجات       | لجنة المشاريع  |

**ملاحظة:** لجنة المشاريع تستطيع تجاوز النوافذ الزمنية في بعض الحالات (مثل إعلان المشاريع وإدارة الفترات).
