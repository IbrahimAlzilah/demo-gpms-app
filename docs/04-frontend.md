# الواجهة الأمامية (Frontend)

## نظرة عامة على الـ Frontend

الواجهة الأمامية مبنية بـ **React** و **TypeScript** و **Vite**، وتقوم بـ:

- عرض واجهة المستخدم (صفحات، جداول، نماذج، أزرار)
- إرسال طلبات HTTP إلى الـ Backend عبر Axios
- حفظ التوكن والمستخدم في المتصفح
- إدارة التوجيه حسب الدور (Routing)
- عرض الإشعارات والرسائل
- دعم اللغة العربية (RTL) والثيم الفاتح/الغامق

## نمط تنظيم المشروع

الواجهة منظمة حسب **الصفحات والميزات** (Page/Feature-based):

- كل ميزة لها مجلد خاص (مثل `proposals`, `groups`, `evaluation`)
- داخل كل ميزة: `api` (خدمات API)، `components`، `hooks`، `list` أو `detail`
- مكونات عامة في `components/common` و `components/ui`
- التوجيه حسب الدور في `routes/`

## تدفق الواجهة (UI Flow)

### 1. تسجيل الدخول

1. المستخدم يفتح `/login`
2. يدخل identifier و password
3. النموذج يرسل POST إلى `/api/auth/login`
4. عند النجاح، يحفظ التوكن والمستخدم في localStorage
5. يُعاد التوجيه إلى لوحة التحكم حسب الدور

### 2. التوجيه حسب الدور

- بعد تسجيل الدخول، يُعاد التوجيه إلى مسار افتراضي حسب الدور:
  - طالب → `/dashboard`
  - مشرف → `/dashboard`
  - لجنة المشاريع → `/dashboard`
  - لجنة المناقشة → `/dashboard`
  - مدير → `/dashboard`

### 3. شريط التنقل (Sidebar)

- يختلف حسب الدور.
- الطالب يرى: لوحة التحكم، مقترحات، مشاريع، مجموعات، طلبات، مستندات، متابعة، درجات.
- المشرف يرى: لوحة التحكم، مقترحات، طلبات الإشراف، مشاريع، تقييم.
- وهكذا لباقي الأدوار.

### 4. الصفحات الرئيسية

| الدور         | صفحات رئيسية                                                                                      |
| ------------- | ------------------------------------------------------------------------------------------------- |
| طالب          | مقترحاتي، مشاريع، مجموعات، رفع مستندات، طلبات، درجات                                              |
| مشرف          | مقترحاتي، طلبات الإشراف، مشاريعي، تقييم المشاريع                                                  |
| لجنة المشاريع | المقترحات، المشاريع، إعلان، تعيين مشرفين، التسجيلات، الطلبات، الفترات، التوزيع، الدرجات، التقارير |
| لجنة المناقشة | المشاريع المعينة، التقييم النهائي                                                                 |
| مدير          | المستخدمون، الإعدادات، التقارير                                                                   |

## الاتصال مع الـ Backend

### Axios

- ملف `src/lib/axios.ts` يُنشئ مثيل Axios باسم `apiClient`.
- العنوان الأساسي: `VITE_API_BASE_URL || "/api"`
- كل طلب يُضاف إليه رأس `Authorization: Bearer <token>`
- في الاستجابة، يتم استخراج `data` من هيكل `{ success, data, message }`

### خدمات API

- كل صفحة/ميزة لها مجلد `api/` يحتوي على ملفات خدمة مثل:
  - `auth.service.ts` — تسجيل الدخول والتسجيل
  - `proposal.service.ts` — المقترحات
  - `group.service.ts` — المجموعات
  - `project.service.ts` — المشاريع
- الخدمات تستخدم `apiClient` لإرسال الطلبات.

## التعامل مع تسجيل الدخول وحماية الصفحات

### ProtectedRouteWrapper

- يتحقق من وجود مستخدم مسجل.
- إذا لم يكن هناك مستخدم → يُعاد التوجيه إلى `/login`.

### RoleBasedRoutesWrapper

- يطابق المسار المطلوب مع المسارات المسموحة لدور المستخدم.
- إذا لم يكن المسار مسموحاً لدوره → يُعاد التوجيه إلى صفحة غير مصرح بها.

### auth.store

- `initialize()`: يتحقق من التوكن عبر `/api/auth/me`.
- عند 401: يُمسح التوكن ويُعاد التوجيه إلى تسجيل الدخول.
