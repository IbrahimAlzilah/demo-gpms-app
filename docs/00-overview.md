# نظرة عامة على المشروع

## 1. فكرة المشروع (Project Idea)

**نظام إدارة تقييم مشاريع التخرج** (GPMS - Graduate Project Management System) هو نظام ويب مصمم لإدارة دورة حياة مشاريع التخرج في الجامعات بدءاً من تقديم المقترحات، مروراً بالموافقات والتسجيل والتقييم، وانتهاءً بنشر الدرجات النهائية.

---

### الهدف الرئيسي من النظام (Main Goal)

يهدف النظام إلى:

1. **توحيد** جميع عمليات إدارة مشاريع التخرج في منصة واحدة بدلاً من استخدام أوراق أو ملفات متفرقة
2. **تنظيم** تدفق العمل وفق أدوار واضحة (طالب، مشرف، لجان) ونوافذ زمنية محددة لكل مرحلة
3. **تسهيل** التواصل بين الطلاب والمشرفين واللجان عبر واجهة موحدة وإشعارات
4. **توفير** تقارير وإحصائيات جاهزة لصناع القرار في اللجان والإدارة

---

### المشكلة التي يحلها النظام (Problem Statement)

في الجامعات، إدارة مشاريع التخرج تتم غالباً **يدوياً** أو بأدوات متفرقة (مثل Excel، البريد الإلكتروني، ورق)، مما يؤدي إلى:

| المشكلة                  | الوصف                                                                         |
| ------------------------ | ----------------------------------------------------------------------------- |
| **تشتت المعلومات**       | بيانات المقترحات والمشاريع والطلاب موزعة على ملفات ورسائل مختلفة              |
| **صعوبة التتبع**         | عدم وضوح حالة كل مشروع (قيد المراجعة، معتمد، مرفوض، في التقدم، مكتمل)         |
| **تعقيد الأدوار**        | الطلاب والمشرفون ولجان المشاريع ولجان المناقشة يعملون بأدوات مختلفة           |
| **غياب النوافذ الزمنية** | عدم وجود آلية واضحة لتحديد مواعيد تقديم المقترحات أو التسجيل أو رفع المستندات |
| **صعوبة التقارير**       | إصدار التقارير والإحصائيات يتطلب جمع يدوي من مصادر متعددة                     |
| **فقدان الشفافية**       | عدم وضوح من فعل ماذا ومتى في مسار العمل                                       |

---

### لماذا نحتاج هذا النظام؟ (Why This System Is Needed)

1. **للمؤسسة التعليمية**: توحيد العملية، تقليل الأخطاء، سرعة إصدار التقارير، مراقبة تقدم الطلاب
2. **للطلاب**: وضوح المسار من البداية للنهاية، إشعارات عند أي حدث، سهولة الوصول للملفات والدرجات
3. **للمشرفين**: متابعة المشاريع المعينة عليهم، إضافة ملاحظات ومعالم، تقييم الطلاب
4. **للجان**: مراجعة المقترحات، إعلان المشاريع، تعيين مشرفين، توزيع لجان المناقشة، الموافقة على الدرجات

---

## أهم المزايا (Features)

| الميزة                    | الوصف                                                                     |
| ------------------------- | ------------------------------------------------------------------------- |
| إدارة المستخدمين والأدوار | تسجيل دخول حسب الدور (طالب، مشرف، لجنة مشاريع، لجنة مناقشة، مدير)         |
| تقديم المقترحات           | الطلاب والمشرفون يقدمون مقترحات مشاريع في نافذة زمنية محددة               |
| المجموعات الطلابية        | إنشاء مجموعات طلابية، دعوة أعضاء، طلبات انضمام                            |
| الموافقة على المقترحات    | لجنة المشاريع تراجع وتوافق أو ترفض أو تطلب تعديل المقترحات                |
| الإعلان عن المشاريع       | لجنة المشاريع تعلن المشاريع المعتمدة للتسجيل                              |
| تسجيل المشاريع            | الطلاب يسجلون على المشاريع كمجموعات في نافذة التسجيل                      |
| توزيع اللجان              | توزيع أعضاء لجنة المناقشة على المشاريع (2–3 أعضاء لكل مشروع)              |
| التقييم والتدرجات         | المشرف يقيّم المشروع، لجنة المناقشة تمنح الدرجة النهائية                  |
| الطلبات                   | الطلاب يقدمون طلبات (تغيير مشرف، مجموعة، مشروع) وتُعالج من المشرف واللجنة |
| المستندات                 | رفع ملفات المشروع (فصول، تقرير نهائي، عرض تقديمي) وفق نوافذ محددة         |
| التقارير                  | تقارير وإحصائيات وتصدير PDF/Excel                                         |
| الإشعارات                 | إشعارات للمستخدمين عند حدث جديد (موافقة، رفض، موعد...)                    |

## المستخدمون المستهدفون

| الدور                                    | الوصف                                     | الصلاحيات الرئيسية                                                                                                         |
| ---------------------------------------- | ----------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| **طالب (Student)**                       | طالب جامعي في مرحلة مشروع التخرج          | تقديم مقترحات، إنشاء مجموعات، التسجيل على مشاريع، رفع مستندات، تقديم طلبات، عرض الدرجات                                    |
| **مشرف (Supervisor)**                    | عضو هيئة تدريس يشرف على مشاريع            | تقديم مقترحات، الموافقة على طلبات الإشراف، تقييم المشاريع، إضافة ملاحظات، إدارة معالم واجتماعات                            |
| **لجنة المشاريع (Projects Committee)**   | لجنة لإدارة دورة مشاريع التخرج            | مراجعة مقترحات، إعلان مشاريع، تعيين مشرفين، معالجة التسجيلات والطلبات، توزيع لجان المناقشة، الموافقة على الدرجات، التقارير |
| **لجنة المناقشة (Discussion Committee)** | لجنة لتقييم المشاريع في المناقشة النهائية | عرض المشاريع المعينة لها، تقييم نهائي ورفع درجات المناقشة                                                                  |
| **مدير (Admin)**                         | إدارة النظام بالكامل                      | إدارة المستخدمين، الإعدادات، التقارير الشاملة                                                                              |

## قاموس المصطلحات (Glossary)

| المصطلح                       | التعريف بالعربية                                                                          |
| ----------------------------- | ----------------------------------------------------------------------------------------- |
| **API**                       | واجهة برمجية تسمح للواجهة الأمامية بالتواصل مع الخادم (Backend)                           |
| **Backend**                   | الجزء الخفي من النظام الذي يعمل على الخادم ويتولى قاعدة البيانات والمنطق                  |
| **Frontend**                  | واجهة المستخدم في المتصفح (صفحات، أزرار، نموذج تسجيل دخول)                                |
| **Token**                     | مفتاح رقمي يُمنح عند تسجيل الدخول ويُستخدم لإثبات هوية المستخدم في كل طلب                 |
| **Middleware**                | برنامج وسيط يفحص الطلب قبل الوصول للمنطق الأساسي (مثل التحقق من الدور أو النافذة الزمنية) |
| **Migration**                 | ملف يصف إنشاء أو تعديل جدول في قاعدة البيانات بشكل نسخي ومتسلسل                           |
| **Seeder**                    | برنامج يملأ قاعدة البيانات ببيانات أولية للتجربة أو الاختبار                              |
| **نافذة زمنية (Time Window)** | فترة زمنية محددة يُسمح فيها بعمل معين (مثل تقديم مقترحات أو رفع مستندات)                  |
| **مقترح (Proposal)**          | عرض مشروع تخرج يقدمه طالب أو مشرف لمراجعته والموافقة عليه                                 |
| **تسجيل (Registration)**      | عملية انضمام طالب أو مجموعة طلاب إلى مشروع معين                                           |
| **لجنة المناقشة**             | لجنة من 2–3 أعضاء تُقيّم مشروع التخرج في المناقشة النهائية                                |
